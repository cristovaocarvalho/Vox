## Vox が選ばれる理由

商用の音声入力ソフトは定期的な月額料金を要求し、入力文字数を制限し、プライベートな音声データを外部サーバーへ送信してモデルの学習に利用します。

**Vox はアーキテクチャのあり方を再定義します。** OS ネイティブの音声ディクテーション体験を提供し、Whisper による文字起こしと先進的な言語モデルによる句読点補正を経て、あらゆる Windows アプリケーションのアクティブなカーソル位置へ直接テキストをストリーミングします。

<br />

## 設計思想

### 完全な自律性（BYOK）
Groq、OpenAI、Azure OpenAI などの主要プロバイダーへ直接 API 接続するか、**Ollama** や **LM Studio** を使用して 100% オフライン・ローカル環境で実行可能。中継サーバーやデータ保持は一切存在しません。

### ネイティブな多言語精度
日本語、英語、ポルトガル語、スペイン語、フランス語、ドイツ語、中国語、イタリア語の **主要 8 言語** にネイティブ対応。不自然な翻訳を挟まず、発話言語のまま正確にテキスト化します。

### コンテキスト認識スマート補正
作業中のアプリケーション環境を自動判別します。IDE でのコード入力、メール作成、メモ書きなど、状況に応じた句読点と記号スタイルを自動適用します。

### シームレスなカーソル入力
グローバルショートカット（`F10` / `F9`）または音声ウェイクワード（*「Vox」*）で起動。音声検出（VAD）が発話終了を自動検知し、カーソル位置へ即座に入力します。

### 制限のないオープンソース
MIT ライセンスのもとで公開。サブスクリプションや利用上限は一切ありません。

## グローバルショートカット

| ショートカット | モード | 動作 |
|:---|:---|:---|
| `F10` | **トグル** | 押して開始、もう一度押す（または無音）で入力 |
| `F9` | **プッシュ・トゥ・トーク** | 押している間録音、離して入力 |
| `F11` | **履歴** | 直近の入力履歴を開いて再利用 |
| *「Vox」* | **ウェイクワード** | 声だけでハンズフリー起動 |

## はじめかた

### 動作要件
* Windows 10 または 11（64-bit）
* [Node.js](https://nodejs.org)（v20+）および npm

### インストール手順

```bash
# リポジトリのクローン
git clone https://github.com/your-username/vox.git
cd vox/code

# 依存関係のインストール
npm install

# 開発環境の起動
npm run dev
```

### パッケージング

```bash
npm run build:win
```
