## サブスクリプションに代わる主権的選択肢

従来の商用音声入力ソフトウェアは、月額課金や不透明な単語制限を課し、プライベートな会話や機密コードを第三者のクラウドサーバーへ送信します。

**Voxは新たなアーキテクチャ基準です。** 洗練されたラグジュアリーなグラスモーフィズムデザインと高性能なネイティブコアを備え、Whisperで音声を高精度に書き起こし、ユーザーが選んだ言語モデルで文脈や句読点を推敲して、あらゆるアプリのアクティブカーソル位置へ直接入力します — サブスクリプションなし、追跡なし、完全なプライバシー保護。

## 主な機能と特徴

### ネイティブ・クロスプラットフォーム動作
**Windows 10/11 (64-bit)** および **macOS (Apple Silicon M1/M2/M3/M4 & Intel)** にネイティブ対応。OSのアクセシビリティレイヤー、アクティブウィンドウ検知、グローバルショートカットにシームレスに統合されます。

### アプリ内ローカルWhisper管理 (100% オフライン)
Whisper GGMLモデル (Tiny, Base, Small, Medium, Large v3, Distil-Whisper) をアプリ内でワンクリックでダウンロード・実行可能。Python環境の構築は不要で、完全オフライン・ゼロ遅延・完全な暗号化セキュリティで動作します。

### BYOK対応 & モデル選択の完全な自由
ワークフローを駆動するモデルはユーザー自身が自由に選択可能。主要なAIプロバイダーに直接接続、またはローカルサーバーを利用可能：
* **クラウドプロバイダー:** Groq, OpenAI, Azure OpenAI, Deepgram, Cerebras, Mistral, Together AI.
* **ローカル環境:** Ollama, LM Studio, vLLM, LocalAI.
* **完全な選択の自由:** 接続先プロバイダーやローカルサーバーで利用可能な任意のSTT（音声モデル）および任意のLLM（言語モデル）を自由に設定可能。

### 高度な文脈補正と自動校正
従来の音声認識で発生しがちな句読点の欠落や同音異義語の誤変換を、選択した言語モデルによるインテリジェント校正エンジンが自動修正し、自然な文章に仕上げます。

### 音声コマンド & アプリ即時起動
キーボードに触れることなく、高度なOS操作やアプリ起動を音声で実行：
* **アプリ起動:** 「VS Codeを開く」「Chromeを開く」「Slackを開く」「Terminalを開く」「メモ帳を開く」「電卓を開く」、または任意のインストール済みアプリを名前で起動。
* **Web検索・情報検索:** 「Chromeを開いてReactのドキュメントを検索」「YouTubeでLo-Fiミュージックを検索」
* **編集・ナビゲーション:** 「改行」「新しい段落」「最後の文を削除」「単語を削除」「すべて選択」「元に戻す」「コピー」「貼り付け」
* **Voxコントロール:** 「コードモード」「テキストモード」「メールモード」「自由口述」「最後の入力を繰り返す」「キャンセル」

### アクティブウィンドウに応じた文脈認識
VS CodeやTerminalでのコーディング時には開発用識別子や構文に、メールやドキュメント作成時には自然な会話文段落に、アクティブウィンドウに応じて自動でフォーマットを最適化します。

### 音声スニペット展開
よく使う定型文を音声トリガーに関連付け。「私の署名」「メールアドレスを入力」「住所を入力」と話すだけで、複数行の整形テキストを瞬時に入力します。

### カスタム口述テンプレート
議事録、技術バグ報告、箇条書き要約など、用途に合わせたプロンプトと音声起動トリガーを持つテンプレートを自由自在に作成・切り替え可能。

### ハンズフリーウェイクワード (*"Vox"*)
ローカルONNX OpenWakeWordニューラルモデルを搭載。キーボードに触れずに「Vox」と呼びかけるだけで、瞬時に音声入力を開始できます。

### 音声アクティビティ検知 (VAD) & オーディオ保護
発話の終了を自動検知して入力を完了。入力中はPCの音声出力を自動ミュートしてハウリングやエコーを防ぎ、終了後に即座に復元します。

### 専門用語・カスタム単語帳
固有名詞、社内用語、プログラミング略語を登録し、常に正確で一貫した表記を保証します。

### 生産性ダッシュボード & コントリビューションマップ
タイピング速度の向上、口述総単語数、節約時間を記録し、GitHubスタイルのヒートマップで毎日の継続状況を可視化します。

### プライバシー金庫と透明な監査ログ
設定、スニペット、テンプレート、履歴はすべて端末内のローカルSQLiteに厳格に保存されます。すべてのAPI通信ログを透明に確認可能です。

## アーキテクチャ比較

| 比較項目 | Vox | 一般的な商用SaaS |
|:---|:---|:---|
| **ライセンス** | オープンソース (MIT) | 商用プロプライエタリ |
| **利用料金** | 永久無料 (BYOK / ローカル) | 年間 25,000円〜50,000円 継続課金 |
| **データプライバシー** | 100%ローカル または API直結 | 第三者サーバー経由 |
| **ローカルオフラインモデル** | アプリ内1クリックダウンロード (Whisper) | 高額プラン限定または非対応 |
| **モデル選択** | 完全自由 (任意のクラウド/ローカルLLM) | 固定された閉鎖型モデル |
| **音声コマンド・アプリ起動** | 任意アプリの起動・Web検索・OS制御 | 基本的な記号入力のみ |
| **対応OS** | Windows 10/11 & macOS (Universal) | 単一プラットフォーム限定 |
| **カスタム単語帳** | ローカルSQLiteで無制限 | 制限あり |
| **利用制限** | 完全無制限 | 月間単語数制限あり |

## デフォルトショートカット

| ショートカット (Win / Mac) | モード | 説明 |
|:---|:---|:---|
| `F10` / `Control+Space` | **音声入力切替** | 押して開始。一時停止または再押下で確定・入力 |
| `F9` / `Option+Space` | **Push-to-Talk** | 押している間だけ録音し、離して即座に入力 |
| `F11` / `Command+Shift+V` | **クリップボード履歴** | 過去の入力履歴を確認・再利用するオーバーレイを表示 |
| *"Vox"* | **ウェイクワード** | ローカルモデルによる完全ハンズフリー起動 |

## はじめに

### 動作要件
* **Windows:** Windows 10 または 11 (64-bit)
* **macOS:** macOS 12 Monterey 以降 (Apple Silicon M1/M2/M3/M4 または Intel x64)
* **Node.js:** Node.js 20+ および npm

### ローカル開発

```bash
# リポジトリのクローン
git clone https://github.com/cristovaocarvalho/Vox.git
cd Vox/code

# 依存関係のインストール
npm install

# 開発環境の起動
npm run dev
```

### ビルドとパッケージング

```bash
# 型チェックとビルド
npm run build

# Windows向けインストーラー作成 (.exe)
npm run build:win

# macOS向けパッケージ作成 (.dmg & .zip)
npm run build:mac

# macOS Apple Silicon向け作成
npm run build:mac:arm64
```
